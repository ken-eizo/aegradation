- Headless source-fidelity test: `ctest --test-dir D:\Developer\Gradation\build -C Release -R gradation_slugui_source_fidelity_tests --output-on-failure`. It asserts precise authored nodes/bounds and preserves ColorPicker original fill layers and 13 hue stops plus Button-State variants.
- 2026-11-23 CPU raster optimization: `picker_raster.hpp` generates the 32f plane/Hue/alpha/preview buffers. Channel bars compute HSV once per row rather than once per pixel; Saturation/Brightness/Alpha color planes precompute hue sectors per column on the stack. Source Figma geometry is unchanged; no allocations are introduced in raster math.
- Headless regression covers **bit-exact RGBA32f results against the previous per-pixel implementation for 7 color axes × 4 raster types**. Release CPU benchmarks: Hue bar ~367.9→28.3 microseconds, Saturation plane ~8092→2130 microseconds in the measured run. These are not GPU transfer or AE start times.
- Limit: matching authored vector geometry and CPU buffer parity are tested, but *pixel-identical final Vulkan/AE screen output* and full AE modal open/close/keyboard behavior are not verified without GUI. Never claim they are.
- On WM_INITDIALOG, the native Color modal is centered, sized, and displayed before CPU/GPU initialization. The Win32 dialog manager continues to own its lifecycle.
- **Numeric keyboard routing (2026-11-23):** Earlier `WM_GETDLGCODE`/DWLP_MSGRESULT fix alone did not resolve reported in-AE typing. An off-screen (never painted) 1×1 native Win32 `EDIT` focus proxy now receives real keyboard messages and forwards them to Slugia's existing numeric/HEX edit model. Mouse clicks on the authored Figma fields place keyboard focus on the proxy without losing Slugia focus. The headless Win32 test delivers characters, Ctrl+A, Backspace, and 8/16/32bpc edits through the actual child WndProc rather than directly fabricating parent WM_CHAR events. This proves the proxy forwarding logic, but does not substitute for an AE GUI test.
- **2026-11-23 HSV square/Hue bar correction (shader-level):** The prior UNORM preference alone was insufficient: `vector.frag` treated all RGBA32F external-image pixels as *linear*, applying `linearToSrgb` on UNORM, while the picker supplies display-encoded sRGB. Slugia now has an opt-in `externalImagesAreSrgb` flag (default off for other clients). On UNORM the picker image RGB passes unchanged; on `_SRGB` fallback it is decoded before framebuffer encoding. Thus the transfer function is performed once regardless of swapchain format, and the original Figma text/geometry remains unchanged. Compiled shader and headless config test pass; final AE GPU screenshot and startup delay remain unverified.
- Gradation enables Slugia's optional in-process 2MiB driver-validated Vulkan pipeline cache. No VkDevice or HWND survives after the modal closes.
- For opt-in startup timings, set GRADATION_PICKER_PROFILE to log font/Figma vs Vulkan creation in OutputDebugStringA. This is not enabled by default.
- Headless CPU timings (2026-11-23): fonts 5.84 ms, Figma scene 5.88 ms, atlas 1.45 ms, initial projection 0.30 ms. Excludes Vulkan startup and AE host event latency.
- Historical backup directories are not active sources; do not create further version directories or delete unique user history without permission.
- 2026-11-23 initial display: CPU/GDI first paint runs during WM_PAINT BEFORE Vulkan initialization, avoiding a blank black modal. It renders numerically calculated color plane, hue and alpha and provisional native controls, replaced by the exact Figma/SlugUI GPU frame once ready. Measured initial CPU paint about 11ms on one Windows system. GPU readiness and user input are still gated by Vulkan initialization; initial controls are temporary and not exactly SVG-identical.
- Screen-relative size: monitor physical work area determines the uniform dialog, SlugUI, input, and cursor scale. FHD uses half the physical size of 4K, maintaining an equivalent share of the display.
- Transparency: Figma authored 10.333333px checker tiles (31/3). Preview color raster upgraded to 172x97 (2x the authored 86x48.5px preview lower half), avoiding uneven half-pixel sampling. Original SlugUI remains byte-identical.
- Eyedropper: original SVG-derived CUR resampled to approximately 20x20 visible pixels and loaded with a cursor dimension proportional to monitor size; resource handles are destroyed at the end.
- Live stop: valid color changes from the dialog are published via optional UI-thread callback (coalesced to at most 60Hz). PF_Cmd_EVENT updates the existing arbitrary-data parameter and requests effect-control redraw via PFAppSuite6::PF_InvalidateRect; OK sends the final color before Vulkan teardown, Cancel restores old RGBA. AE may defer some updates while a modal event remains open, so this does not guarantee live comp rendering until verified in AE.
- 2026-11-24 GPU startup optimization: Slugia now uploads the atlas curve and band textures with ONE Vulkan command submission and ONE vkQueueWaitIdle, instead of two submissions/two waits. Both staging buffers remain mapped and alive until the combined transfer completes, then are destroyed. Vector and coverage graphics pipelines are submitted as a single vkCreateGraphicsPipelines batch (primitive pipeline remains separate). Shader code and image precision remain unchanged. Driver-dependent actual startup improvement is NOT yet measured in the host.
- 2026-11-24 optional initialization breakdown: set GRADATION_PICKER_PROFILE in the AE process to emit stage-level milliseconds to OutputDebugStringA: Vulkan instance, surface/device, atlas transfer, buffers/descriptors, swapchain+pipelines, frames, followed by first GPU submission. There is no background worker, persistent VkDevice, or extra window.
- 2026-11-24 32bpc numeric presentation: RGB/A displays at most FOUR decimal digits (e.g. 0.8065, 0.5, 1, 0). Formatting does not quantize internal RGBA float32 values; direct numeric entry still parses full float32 precision. Figma input geometry and 8/16bpc formatting remain unchanged.
